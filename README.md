# Recon-X

A small desktop app for early-stage web reconnaissance. From one window it runs
subdomain discovery, directory and file checks, and technology fingerprinting
against a target, together or separately.

It is built with Python and an Eel (HTML/CSS/JS) front end, so it has a real
interface rather than a command line.

![Recon-X](https://github.com/user-attachments/assets/deafc795-62e5-4e69-ac2c-f1904da0b68c)

## Requirements

Python 3.8+.

```
pip install eel requests
```

## Usage

```
python app.py
```

Or double-click `run.bat` on Windows.
